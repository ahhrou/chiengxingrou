什么是 Rational Numbers？

有理数包括：整数 Integers、分数 Fractions、小数 Decimals，可以是正数、负数或零。

Positive 正Zero 零Negative 负
+5, +2, +1.50-5, -2, -1.5
0 不是正数，也不是负数。负数不代表错误，只是代表“相反的状态”：温度 -5°C、欠别人 RM10。

Integers 整数

…, -3, -2, -1, 0, 1, 2, 3, …　不是整数：½、1.5、-2.7

比较大小 Comparing

><=
Greater than 大于Less than 小于Equal to 等于
数轴 Number Line：越往右越大。-2 > -5，因为 -2 在 -5 的右边。负数越靠近 0 越大。

四则运算规则

Addition 加同号相加，保留符号；异号相减，跟绝对值大的符号
Subtraction 减减去负数 = 加上正数：5 − (−2) = 5 + 2 = 7
Multiplication 乘同号正，异号负
Division 除同号正，异号负

Fractions 分数 & Decimals 小数

Numerator 分子（上）／Denominator 分母（下）。分母不同时，先找 Common denominator 公分母。

除以分数 = 乘以倒数 (Reciprocal)：12 ÷ 14 = 12 × 41 = 2

小数加减法要把小数点对齐。2.35：2 个位 Ones，3 十分位 Tenths，5 百分位 Hundredths。

谁是有理数？

能写成 ab（a、b 是整数，b ≠ 0）的数。整数 5 = 51；有限小数 0.5 = 12；循环小数 0.333… = 13，都是有理数。π 和 √2 不是。

📖 Part 1 · Integers 整数

① 先认识三个词

Positive 正数（大于 0）、Negative 负数（小于 0）、Zero 零（不正也不负）。

② 什么是整数？

数值没有分数部分的数：…, −2, −1, 0, 1, 2, …
✔ −5、0、8　✘ ½、1.5、−2.7

③ 负数在生活里

零下 5°C = −5；欠别人 RM10 = −10；存款 RM10 = +10。负数只是“相反的状态”，不是错误。

④ 数轴 Number Line

像横放的温度计：越右越大，越左越小。

⑤ 比大小

正数 > 0 > 负数。两个负数比较时，离 0 越近越大：−1 > −3 > −6。

⚠️ 常见错误：以为 −5 > −2（因为 5 > 2）。不确定时，先画数轴！

📖 Part 2 · 整数四则运算

➕ Addition 加法

想像“有钱 = 正、欠钱 = 负”。
同号：数字相加，保留符号。(−3)+(−2)：欠 3 又欠 2 = 欠 5，所以 −5。
异号：大的数字减小的数字，符号跟数字较大的那个。(+5)+(−3) = +2；(−5)+(+3) = −2。

➖ Subtraction 减法

口诀：减去一个数 = 加上它的相反数。
5 − (−2) = 5 + 2 = 7　　−5 − (−3) = −5 + 3 = −2
步骤：① “−”变“+” ② 后面的数变号 ③ 用加法规则。

✖️➗ Multiplication 乘法 & Division 除法

Same signs = Positive；Different signs = Negative。
(−3)×(−2) = +6　　3×(−2) = −6　　12 ÷ (−4) = −3
步骤：① 先决定符号 ② 再算数字。

⚠️ 加法和乘法规则不同：(−3)+(−2) = −5，但 (−3)×(−2) = +6。

🧮 整数四则运算练习

📖 Part 3 · Fractions 分数

Numerator 分子（上） / Denominator 分母（下）。负号通常写在分数前面：−½ = (−1)/2。

加减法

分母相同：分子加减，分母不变。¾ − ¼ = 2/4 = ½。
分母不同：① 找 Common Denominator 公分母 ② 通分 ③ 分子加减 ④ Simplify 化简。
½ + ⅓ = 3/6 + 2/6 = 5/6

乘法

分子×分子，分母×分母，符号规则同整数。½ × ⅔ = 2/6 = ⅓；−½ × ⅔ = −⅓

除法

除以一个分数 = 乘以它的 Reciprocal 倒数。½ ÷ ¼ = ½ × 4/1 = 2

化简

分子分母同除以公因数：4/6 → 2/3。

📖 Part 4 · Decimals 小数

2.35：2 = Ones 个位，3 = Tenths 十分位，5 = Hundredths 百分位。
0.1 = 1/10，0.01 = 1/100。

加减法

小数点对齐！2.50 − 1.25 = 1.25。符号规则同整数。

乘除法

1.2 × 2 = 2.4；(−1.2) × 2 = −2.4；4.8 ÷ 2 = 2.4；(−4.8) ÷ 2 = −2.4。

⚠️ 0.5 比 0.45 大！比较小数先把位数补齐：0.50 vs 0.45。

📖 Part 5 · Rational Numbers 有理数

能写成 a/b（a、b 是整数，b ≠ 0）的数，就是有理数。口诀：能变成分数 = 有理数。

为什么？

整数：5 = 5/1，−3 = −3/1
有限小数：0.5 = 5/10 = ½，1.25 = 5/4
循环小数：0.333… = ⅓

不是有理数

π、√2 不能写成两个整数的分数。

关系图

整数、有限小数和循环小数都属于有理数（可以是正、负或零）。所以：每个整数都是有理数，但不是每个有理数都是整数（½ 不是整数）。
